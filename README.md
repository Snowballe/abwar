# Abwar - Application Flutter

## Description
Abwar est une application mobile développée avec Flutter, permettant de créer des applications multiplateformes (Android, iOS, Web, Desktop).

## Structure du projet
```
abwar/
├── abwar_flutter/          # Projet Flutter principal
│   ├── android/           # Configuration Android
│   ├── ios/               # Configuration iOS  
│   ├── lib/               # Code source Dart/Flutter
│   ├── pubspec.yaml       # Dépendances et configuration
│   └── ...
├── docs/                  # Documentation du projet
└── README.md              # Ce fichier
```

## Démarrage rapide

### Prérequis
- Flutter SDK installé
- Android Studio / Xcode (pour le développement mobile)
- VS Code recommandé

### Installation
1. Cloner le repository
2. Naviguer dans le dossier Flutter : `cd abwar_flutter`
3. Installer les dépendances : `flutter pub get`
4. Lancer l'application : `flutter run`

### Plateformes supportées
- ✅ Android
- ✅ iOS  
- ✅ Web
- ✅ Windows
- ✅ macOS
- ✅ Linux

## Développement
Le code principal se trouve dans `abwar_flutter/lib/` avec une architecture organisée par écrans et modèles.

## Build et déploiement
- **Android** : `flutter build apk` ou `flutter build appbundle`
- **iOS** : `flutter build ios`
- **Web** : `flutter build web`

## Documentation
Consultez le dossier `docs/` pour plus d'informations sur l'installation et l'utilisation.
